raw는 앞뒤 silence와 저주파 노이즈가 그대로 들어가기 때문에 평균 입력 길이와 chunk 수가 늘어난다.  
K4/P5 보정은 HPF와 adaptive trim으로 불필요한 구간을 줄여서 CER와 WER를 모두 낮췄다.

## 6. direct-match 실험 문서 기반 결론

이전 문서들에서 USB mic 녹음 WAV와 mel을 direct WAV에 가깝게 만드는 시도를 많이 수행했다.

관련 문서:

- `docs/mic_gap_analysis/ANALYSIS_USB_MIC_20260426.md`
- `docs/mic_gap_analysis/HANDOFF_USB_MIC_GAP_20260426.md`
- `/Users/nsbb/hdc_labs/work/stt/device_test/mic_gap_experiments_20260426/USB_MIC_DIRECT_MATCH_ATTEMPT_20260426.md`
- `/Users/nsbb/hdc_labs/work/stt/device_test/file_only_research/USB_MIC_TO_DIRECT_WAV_RESEARCH.md`

확인된 내용:

- EQ, RMS norm, FIR tilt, spectral subtraction, expansion, WPE, HEQ, mel norm 변경 등은 feature distance를 일부 줄이더라도 CER가 좋아지지 않거나 오히려 악화됐다.
- mel을 direct처럼 보이게 강제 변환하면 모델이 학습 때 본 입력 분포와 달라져서 STT가 망가지는 경우가 많았다.
- 특히 HEQ나 mel-domain normalization 변경은 direct-like 지표를 개선해도 CER를 크게 악화시켰다.
- K4/P5처럼 자연스러운 입력 정리, 즉 HPF + adaptive trim + chunk merge 보정은 실제 CER 개선으로 이어졌다.

따라서 결론은 다음과 같다.

> 목표를 "direct WAV/mel과 수치적으로 최대한 같게 만들기"로 잡으면 안 된다.  
> 모델이 안정적으로 해석할 수 있는 mic 입력 분포를 유지하면서, noise/silence/chunk 문제만 줄이는 방향이 현재는 가장 효과적이다.

## 7. 현재 결론

1. USB mic 51 + K4/P5 보정 전체 평균 CER는 16.251%다.
2. 기존 DMIC 전체 평균 22.36%와 비교하면 USB mic 51 쪽이 낮다.
3. USB raw clean300은 16.645%, K4/P5 clean300은 13.173%로 보정 효과가 명확하다.
4. direct WAV 수준인 7~9%까지는 아직 갭이 남아 있다.
5. 단순 direct-match 신호 변환은 이미 여러 방식에서 한계를 보였다.
6. 단기적으로는 K4/P5 유지가 맞고, 더 낮추려면 beam search/TTA/domain correction 또는 모델 fine-tune이 다음 후보가 된다.
